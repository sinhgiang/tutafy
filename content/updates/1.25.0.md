- The home page, the upgrade page and the switch page show the same lines for Free, Pro and Academy, and nothing is listed twice. Prices are the same as before: $0, $12 and $29 a month.
- We removed "Priority support" from Academy, because there is no separate support queue yet. The lists now name what each plan really unlocks, such as lesson packages, coupons, waitlist and custom domain.
- If you press Go Pro or Start Academy before you have an account, you sign up first and then land on the upgrade page for the plan you picked, with that plan marked.
- If you cancel Pro or Academy, you keep it until the end of the period you already paid for. It does not stop the moment you cancel.
- If payment is not available, the upgrade page now says so instead of showing a button that does nothing.
