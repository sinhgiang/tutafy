title: Import tells you which rows it could not use
summary: Before and after an import, Import lists the rows it left out and why, and gives you a file with all of them.
image: /updates/import-problems.webp
imageAlt: The Import preview with a box listing four rows that cannot be imported and a button to download them as a CSV file
---
- When you choose a file, Import now shows a box with every row it cannot use, such as a lesson date it cannot read or a row with no student.
- Each line says which row it is, which student it belongs to and what happens: the row is skipped, or the student is added without that lesson.
- Press Download the problems as a CSV file to get the whole list, ready to fix in a spreadsheet and import again.
- After the import the same box lists anything that could not be saved, in plain words.
