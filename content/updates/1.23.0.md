title: Say which languages you teach
summary: Settings now has a "Languages you teach" box, so your profile and the tutor directory can show them. Profiles with no introduction are no longer offered to search engines.
image: /updates/languages-field.webp
imageAlt: The Languages you teach box in Settings, Profile. It holds Spanish, English, Portuguese, a Save languages button, a line explaining that languages are separated by commas and a green line saying the languages were saved and show on the public profile
---
- New in Settings, Profile: "Languages you teach". Type up to six languages separated by commas and press Save languages. They show on your public profile and on your card in the tutor directory.
- Students can only filter the directory by a language that a tutor has listed, so a profile with no language cannot be found that way. Add yours.
- Search engines are now asked to list only profiles with an introduction of 80 characters or more. A shorter profile still works and can be booked; write more and it is offered to search engines too.
