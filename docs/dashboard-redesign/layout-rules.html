Layout rules

Four kinds of page. Each fills its frame; the frame is centred. No page keeps a fixed width that sticks to the left.

0 · The frame (every page)

Sticky sidebar (232 px, an icon rail from 768 to 1279 px, a bottom bar below 768). Sticky top bar. The content sits in one frame: up to 1440 px wide, centred with margin: 0 auto, 32 px side padding (24 px on tablet, 16 px on a phone).

1 · Overview and charts

Dashboard, Earnings, Reports. A 12-column grid inside the frame. KPI cards span 3, a main chart 8, a ranking 4, a table 12. Below 1280 px KPIs go two across and charts stack. Nothing is capped to 900 px.

2 · Tables and lists

Students, Lessons, Waitlist, Coupons, Packages, Subscriptions, Team. The table uses the whole frame. A toolbar sticks above it (search, filters, sort, export). Selecting rows shows a bulk bar. From 1280 px a row can open a side panel instead of a new page. Below 768 px each row becomes a card.

3 · Forms and settings

Settings, Availability, Import, new lesson, new student. A section list on the left (sticky), the form in a readable column (up to 720 px), and from 1440 px a live preview or help on the right (for example, the booking page as students see it). The whole group is centred in the frame. Focused one-step flows (add a student, new lesson, Upgrade) are one centred column of 720 px.

4 · Workspaces

Calendar and Messages use the full height and width of the frame. Calendar: week view by default on a computer, day list on a phone, a mini month and a lessons-today column on the right. Messages: three panes, the conversation list (320 px), the thread, and a student card (300 px, from 1440 px).
