# T-1064: One-off letter to the tutors, from the admin's own page

`/super-admin/announcement` (`src/app/(admin)/super-admin/announcement/page.tsx`, buttons in `AnnouncementControls.tsx`; linked from the Super admin page) lets the platform admin send the approved letter "Two minutes to get your Tutafy profile ready for students" to the tutors who qualify, one tutor every 3 minutes. Only the admin can open it or call it; nothing runs by itself.

- **Who gets it.** The tutors the sitemap lists (public page on, a real introduction, not a test account, not a copy of another profile: `src/lib/profile-index.ts`), with a plain address, once per address, minus the addresses in `email_optouts`. At most 60 (`MAX_RECIPIENTS`); more than that and Start refuses. The rule is `pickRecipients` in `src/lib/tutor-announcement.ts`; the page shows how many a Start would queue.
- **Three buttons, three admin-only routes** (`src/app/api/admin/announcement/{test,start,stop}/route.ts`). Each calls `adminApiGate()` first (401 signed out, 403 for any account that is not `ADMIN_EMAIL`), then `sameOriginGate()` (403 for a foreign Origin), then does its work.
  - "Send me a test": ONE mail to the address on the admin's own session (never from the request), marked `[Test]`, sent at once; 3 a minute at most. It unlocks Start for 7 days.
  - Start: shows a confirm box with the number of tutors; the number goes to the server as `expected` and the server refuses if the real number is different (409 with the real one). Refused too without a recent test, without `RESEND_API_KEY`, or without `UNSUBSCRIBE_SECRET` (a mail without a working unsubscribe link is never sent).
  - Stop: marks every mail not yet handed over as cancelled and asks the mail service to take back each handed-over mail whose time has not come. A mail whose time has passed has gone and is only counted. A Start that is still handing mails over sees the stop and hands over no more.
- **Why three minutes work without a cron.** The hosting runs scheduled jobs once a day, so the spacing is the mail service's own: each mail is handed to Resend with `scheduledAt` (first one 90 seconds after Start, then exactly `SPACING_MS` = 3 minutes apart, never closer than 3 minutes to a mail already waiting). Nothing needs to stay open. `slotTimes` and `firstSlotAt` are the whole rule.
- **Once for each tutor.** Table `tutor_announcement_sends` (migration `030_tutor_announcement.sql`, **not applied: the owner runs it**): one row per (campaign, tutor), written BEFORE the mail service is asked. The new rows of a Start are one single insert (all or none), so two Starts at once cannot split the list; a repeat finds the rows and queues nobody. A failed or cancelled tutor may be queued again by the next Start (attempt + 1, a new idempotency key). Table `tutor_announcement_control` holds when the test went and when Stop was pressed. Both tables have row level security on, no policy, and no rights for the browser's roles.
- **Status.** The page shows the setup checks (admin address, mail key, unsubscribe key, migration), the counts (waiting, sent, queued but not handed over, cancelled, failed), the next and last time, and one row per tutor by NUMBER only. "Sent" means the scheduled time has passed; the mail service is not asked about delivery.
- **No personal data kept.** The queue stores the tutor's id, a state, a time, the mail service's id and its error NAME. No address, no name and no error text is stored, shown, answered or logged.
- **Mail.** `createMailer(..., 'general')`: sender `Tutafy` at the site's booking mailbox, Reply-To the support mailbox, a plain-text copy, `List-Unsubscribe` headers and a footer link (the same signed link as the welcome series). `createMailer` gained `scheduledAt`, an idempotency key and `cancel`.
- **Words** are in the two admin languages (`ann.*` keys in `src/lib/admin-i18n.ts`).

Tests: `tests/tutor-announcement.test.ts` (29 tests: rules, migration and the second-person test, 401/403/Origin on every route, the test mail goes only to the session address, Start needs a test and the right number, 24 tutors once each at exact 3-minute steps, a second and a simultaneous Start queue nobody twice, Stop and Start after Stop, a refusing or throwing mail service, the page shows no name or address). `tests/support/pglite-client.ts` gained `update(...).select()`.

Not done: delivery is not read back from the mail service (a mail that bounces shows as "Sent"); one campaign (`tutor-profile-2026-10`) only; the letter's words are in code, so a changed letter is a code change.
