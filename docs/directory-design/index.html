A tutor directory that lists only tutors you can book

Today /tutors lists up to 50 tutors whose booking page is switched on, but only 6 of 724 tutors ever chose free hours, so almost every card leads to someone nobody can book. These pages show the directory once it lists only bookable tutors, and every card says when the tutor is next free.
